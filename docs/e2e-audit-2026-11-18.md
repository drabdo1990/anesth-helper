## Findings

1. **Stale user-facing copy (real defect).** `src/views/ConditionsView.tsx:96` says "Six have a perioperative plan; the rest point to their chapter." The README and git history say all 110 conditions have full plans, and a spot check of Marfan confirms it. A clinician reading that line is told the app is less complete than it is.
2. README test count ("212 tests") is out of date (actual: 433).
3. Data banner shows `DATA_VERSION 2026.11.17-DRAFT25`: the app itself still states clinical sign-off is pending. Not a bug, but an audit-relevant fact.

## Not covered
- Only a sample of the 110 condition plans, not every one.
- CICO and MH flows opened but not stepped through; LAST was only read, not interacted with.
- Offline/service-worker behaviour, mobile viewport (320 px), dark theme, and keyboard-only navigation.
- Clinical correctness of source values (needs a clinician, not a test).
- The repo has no automated E2E suite (no Playwright/Cypress). These flows were driven by hand and are not repeatable by CI.
