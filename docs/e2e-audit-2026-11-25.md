## Findings

1. **SOS hid all emergency steps until a weight was entered (safety-relevant, FIXED).** With no weight set, opening SOS on LAST or MH showed only "Enter actual body weight above to calculate doses." The non-dose first steps ("Stop injecting. Call for help. Give 20% lipid emulsion", the MH first-response steps) and the step checklist were not shown, because `EmergencyOverlay.tsx` swapped the whole panel for a prompt. Not caught on 11-18 because that run entered a weight first. Evidence of the defect: `docs/e2e-audit-2026-11-25-sos-no-weight.png`.
   **Fix:** `LastPanel` and `MhPanel` now take `weightKg: number | null`. The warning banner, MH hotline and step checklist always render; only the weight-based dosing and cumulative-tracker blocks (now `LipidDosing` / `DantroleneDosing`) are replaced by the shared `NeedWeight` prompt (`src/components/emergency/NeedWeight.tsx`). Weight-entered behaviour is unchanged (F13, F14 still pass).
   **Verification:** F19/F20 were first written as `test.fail()` known-defect tests; after the fix they reported "Expected to fail, but passed", the annotations were removed, and they now run as regression guards. Full run after the fix: tsc clean, 451 unit tests, build, 21 of 21 E2E.
2. **Stale copy (open).** `src/views/ConditionsView.tsx:105` doc comment still says "plans for the first six, chapter pointers for the rest". README line 24 says 433 tests (now 451) and its Diseases row says "110 conditions" (now 185, with a new "Emergency" and board-subspecialty category).
3. **Behaviour change to be aware of.** The 11-18 report recorded under-18 as "adult dosing withheld". It is now a pediatric mode with a warning when adult mode is chosen. F4 reflects the new behaviour. Pediatric dose values themselves were not checked beyond the mode switch.
4. **Usability observation, not a defect.** SOS > CICO opens on Plan A (tracheal intubation); the front-of-neck steps are one tap away under Plan D.
5. `DATA_VERSION` 2026.11.25-draft27 and the "needs clinician sign-off" banner remain: all content is draft until reviewed.

## How to run
`npm run test:e2e` (starts the dev server on 5173 if not already running; uses the installed Chrome, no browser download; retries are off on purpose). Output: `e2e-results.json`, failure screenshots/traces in `e2e-artifacts/` (both git-ignored).

## Not covered
- Clinical correctness of any dose or plan text (needs a clinician).
- Pediatric dose values, other populations, and the local-anesthetic and neuraxial calculators.
- MH and CICO timers/step interaction beyond rendering, lipid logging buttons.
- Offline/service-worker behaviour, dark theme, keyboard-only navigation, real touch devices and Safari.
- The suite ran against the dev server, not the production build.

## Method notes
Three of the first-run failures were bugs in my own spec (ambiguous "Male"/"Pediatric" locators, a hidden duplicate checklist counter, `role=radio` vs `button`), fixed in two rounds and re-run; none were app defects. No check was loosened to get green.
