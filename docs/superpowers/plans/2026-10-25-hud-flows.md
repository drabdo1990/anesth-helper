# HUD Shell + Flow-style Airway, Vent and Dosing Implementation Plan

> **For agentic workers:** Execution method chosen by the user: one agent per part, run in parallel waves, with the main session acting as harness (merge, verify). Steps use checkbox syntax. Final home of this file: `docs/superpowers/plans/2026-10-25-hud-flows.md` (copy it there when plan mode ends).

**Goal:** Make the app glanceable and fast: a HUD look, and Dosing / Airway / Vent each driven by a short ordered checklist or shortcut instead of long reference text.

**Architecture:** Wave 1 builds a small shared HUD kit (`src/components/hud/*`) plus one pure helper (`src/lib/flow.ts`). Wave 2 runs three agents in parallel, each owning separate files: Dosing (`situations.ts`, `DosingView.tsx`), Airway (`airwaySummary.ts`, `AirwayView.tsx`), Vent (`ventFlow.ts`, `VentilationView.tsx`). Logic lives in pure `.ts` modules with vitest tests; views only render.

**Tech Stack:** React, TypeScript, Tailwind 3.4 (dark-only), zustand, vitest 3 (node environment, `src/**/*.test.ts` only), lucide-react.

**Spec:** the design discussed in this session (written back to the user; this plan is the written form). No separate spec file.

## Global Constraints
- No new dependencies. No jsdom / testing-library: tests are `.test.ts`, pure logic only.
- Verify with `npm test` and `npm run build` (`tsc -b && vite build`). No lint script exists.
- Dark-only theme. Use Tailwind `clinical.*` tokens (`bg`, `card`, `border`, `cyan`, `red`, `emerald`, `amber`) and `shadow-glow-*`; do not add new hex values.
- Keep the permanent disclaimer, `SourceBadge` and `NoSourceValue` behaviour. Never display an unsourced number as if sourced.
- No invented clinical content: situations and flow steps use only existing ids/calcs/data. Any new clinical grouping needs user confirmation before merge.
- Touch targets stay >= 48px. Keep `role="checkbox"` semantics in `ChecklistItem`.
- Commits use `feat:` / `fix:` / `test:` / `docs:` prefixes; one worktree and branch per agent.

## Review Focus
- No weight / height / sex entered: every new HUD summary shows a prompt or "no value", never `NaN` or a stale number.
- Pediatric patient (age < 18): Vent flow must not mark VT done from an adult target; Airway summary must use pediatric calcs.
- Situation lists referencing a drug id that is later renamed: test fails instead of silently showing nothing.
- Scenario with no VT range (`laparoscopic`): flow marks the VT step as needing manual judgement, not "done" or "out of range".
- Plateau exactly at the limit counts as OK; one above does not.
- Long checklist state surviving tab switches (flow state is derived from the store, not local `useState`).

```ts
export interface FlowStep { id: string; label: string; done: boolean; hint?: string }

/** Index of the first undone step; steps.length when everything is done. */
export const currentStepIndex = (steps: FlowStep[]): number => {
  const i = steps.findIndex((st) => !st.done);
  return i === -1 ? steps.length : i;
};
```

```ts
import { adultEttAndBlade, dltSizeForHeight, lmaSizeForWeight, pedsBladeForAge, pedsEtt } from './airway';

export interface AirwaySummaryInput {
  population: 'adult' | 'pediatric';
  ageYears: number | null; sex: 'male' | 'female' | null;
  heightCm: number | null; weightKg: number | null;
}
const none = { ok: false as const, reason: 'Enter patient value' };

export const airwaySummary = (i: AirwaySummaryInput) => {
  const ped = i.population === 'pediatric';
  return {
    ett: ped ? (i.ageYears == null ? none : pedsEtt(i.ageYears, 'cuffed-msd')) : adultEttAndBlade(i.sex),
    blade: ped ? (i.ageYears == null ? null : pedsBladeForAge(i.ageYears * 12)) : adultEttAndBlade(i.sex),
    lma: i.weightKg == null ? none : lmaSizeForWeight(i.weightKg),
    dlt: ped ? none : dltSizeForHeight(i.heightCm, i.ageYears),
  };
};
```
(Adjust only if the real result types make a line fail `tsc`; do not change calc behaviour.)

```ts
import type { FlowStep } from './flow';
import type { VentilationScenario } from '../data/types';
import { PLATEAU_LIMIT_CMH2O } from './calc/ventilation';

export interface VentFlowInput {
  scenario?: VentilationScenario; ageYears: number | null;
  heightCm: number | null; sex: 'male' | 'female' | null;
  mlPerKgPbw: number | null; respiratoryRate: number | null;
  peepCmH2O: number | null; plateauCmH2O: number | null;
}

export const ventSteps = (i: VentFlowInput): FlowStep[] => {
  const r = i.scenario?.tidalVolumeMlPerKgPbw;
  const peds = i.scenario?.id === 'pediatric' || (i.ageYears != null && i.ageYears < 18);
  const limit = i.scenario?.plateauPressureLimit ?? PLATEAU_LIMIT_CMH2O;
  return [
    { id: 'scenario', label: 'Pick scenario', done: !!i.scenario },
    { id: 'pbw', label: 'Height + sex (predicted body weight)', done: i.heightCm != null && i.sex != null },
    { id: 'vt', label: 'Set tidal volume in range', done: !peds && !!r && i.mlPerKgPbw != null && i.mlPerKgPbw >= r.min && i.mlPerKgPbw <= r.max,
      hint: peds ? 'Pediatric: no adult target' : !r ? 'No sourced range: clinician judgement' : undefined },
    { id: 'rate-peep', label: 'Set rate and PEEP', done: i.respiratoryRate != null && i.peepCmH2O != null },
    { id: 'plateau', label: `Plateau <= ${limit} cmH2O`, done: i.plateauCmH2O != null && i.plateauCmH2O <= limit },
  ];
};
```
